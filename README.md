# DopeToolsCollection
## Useful Super Units and Custom Units for _Unity Visual Scripting_ also known as _Bolt_.

## Module/dependency notes

DopeTween and the pure macro folders are isolated from optional package integrations with assembly definitions. You no longer need to remove unused folders just because **Advertisement Legacy** or **Mobile Notifications** is missing.

- DopeAds C# units compile only when Unity's **Advertisement Legacy** package (`com.unity.ads` 4.x) is installed.
- DopeNotifications C# units compile only when Unity's **Mobile Notifications** package (`com.unity.mobile.notifications` 2.4+) is installed.
- Bolt / Unity Visual Scripting is still required for the custom units.
